# Жоғалған үй жануарларын іздеуге арналған веб-сервис

## 📌 Жобаның мақсаты
Бұл веб-қосымша иелерінен адасып кеткен үй жануарларын (ит, мысық және т.б.) тез табуға, хабарландырулар жариялауға және көмек көрсеткісі келетін еріктілер мен іздеушілерді өзара байланыстыруға арналған платформа.

## 🚀 Негізгі мүмкіндіктері мен функциялары
* **Пайдаланушыларды тіркеу және кіру (Authentication):** Жеке кабинет құру және қауіпсіз кіру жүйесі.
* **Хабарландырулар қосу (Create):** Жоғалған немесе табылған жануар туралы сурет, мекенжай және сипаттама қосып жариялау.
* **Іздеу және сүзу (Search & Filter):** Жануардың түрі, мекенжайы немесе жоғалған күні бойынша жылдам іздеу.
* **Өңдеу және жою (Update & Delete):** Пайдаланушы өз хабарландыруларын өңдей алады немесе тапқан жағдайда жоя алады.

## 📄 Негізгі беттер тізімі
1. **Басты бет (index.php):** Соңғы қосылған хабарландырулар лентасы және іздеу панелі.
2. **Тіркелу / Кіру беттері (register.php / login.php):** Жүйеге кіруге арналған формалар.
3. **Хабарландыру қосу беті (add_pet.php):** Жаңа жануар туралы ақпарат енгізу формасы.
4. **Жеке кабинет / Жеке хабарландырулар (profile.php):** Қолданушының өз жарияланымдарын басқару беті.

## 🗄️ Дерекқор құрылымы (MySQL - 3 негізгі кесте)
1. **`users` кестесі (Пайдаланушылар):**
   * `id` (PK)
   * `username`
   * `email`
   * `password` (хештелген пароль)
2. **`pets` кестесі (Хабарландырулар / Жануарлар):**
   * `id` (PK)
   * `user_id` (FK -> users.id)
   * `title` (Тақырыбы: Мысалы, "Алматы қаласында ит жоғалды")
   * `category` (Түрі: Ит, Мысық және т.б.)
   * `description` (Толық сипаттамасы, мекенжайы)
   * `photo` (Сурет файлының жолы)
   * `status` (Күйі: Жоғалды / Табылды)
   * `created_at` (Қосылған уақыты)
3. **`messages` немесе `comments` кестесі (Пікірлер / Байланыс):**
   * `id` (PK)
   * `pet_id` (FK -> pets.id)
   * `user_id` (FK -> users.id)
   * `comment_text`
   * `created_at`
